# Security policy

## Reporting

Report security concerns through the authorised private repository channel for the programme. Do not open public issues or publish details externally.

## Sensitive material

Do not commit:

- Access tokens, API keys, credentials, or private certificates.
- Customer data or protected health information.
- Export-controlled material.
- Private model weights or gated model artefacts.
- Production endpoint identifiers.
- Confidential incident reports.

## Agent use

Agents must not print, store, transform, or transmit secrets. Any agent output used for training, deployment, safety acceptance, or governance requires human review.
